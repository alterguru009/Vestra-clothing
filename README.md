# VESTRA — Wear Your Story

A premium clothing brand e-commerce website built with pure HTML, CSS and vanilla JavaScript.

## ✨ Features

- 🛍️ Product catalog with category filters
- 🛒 Add to cart with slide-in drawer
- ❤️ Wishlist functionality
- 👁️ Product detail page with size & colour selection
- 💳 UPI payment checkout (4-step flow)
- 📦 Order summary with coupon codes
- ✅ WhatsApp order confirmation
- 🔄 7-day easy returns
- 📱 Fully responsive design

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript (no frameworks)

## ⚙️ Setup

1. Download or clone this repository
2. Open `index.html` in any browser
3. To change WhatsApp number, edit `WHATSAPP_NUMBER` in the script section

## 📞 WhatsApp Integration

Update the number in `index.html`:

const WHATSAPP_NUMBER = '91XXXXXXXXXX';
